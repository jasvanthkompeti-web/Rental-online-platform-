# RentX 5-File Electronics Rental

Files:
1. index.html
2. app.js
3. style.css
4. README.md
5. render.yaml

Features:
- 8 electronics products displayed directly in the frontend
- Laptops, iPhones, cameras, tablet and gaming console
- Search and categories
- Add to cart
- Quantity controls
- Rental dates
- Automatic rental + security deposit bill
- Clickable Pay Now demo
- Payment marked SUCCESSFUL
- Invoice number and printable bill
- Cart stored in browser localStorage

Important: The Pay Now button is a DEMO payment. It does not process real money or collect card details.
